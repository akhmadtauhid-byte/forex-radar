FOREX RADAR

siap
Forex dan emas biasanya diperdagangkan dengan leverage, sehingga rugi bisa lebih besar dari modal setoran. Sistem ini alat bantu analisa, bukan jaminan untung. Tab harus tetap terbuka agar pembaruan otomatis jalan.
Batas gratis Twelve Data adalah 8 permintaan per menit, jadi memuat banyak pasangan memakan waktu. "Bandingkan otomatis" menguji 3 timeframe dan 3 mode untuk semua pasangan dan memerlukan sekitar 3 menit.

Posisi terbuka

Riwayat

Kunci API gratis: daftar di twelvedata.com, lalu salin API key dari dashboard dan tempel di bawah. Paket gratis: 8 permintaan per menit dan 800 per hari. Kunci hanya tersimpan di browser perangkat ini.
Spread dalam pip dan ukuran pip bawaan hanyalah perkiraan. Isi spread sesuai akun Finex Anda (lihat di MetaTrader 5, kolom spread), misalnya EUR/USD=1.0, XAU/USD=2.5. Untuk emas, 1 pip dihitung 0,10 dolar. Biaya swap (bunga menginap) tidak dihitung.
Bukan saran investasi. Trading forex dan CFD berisiko tinggi, termasuk kehilangan seluruh modal.
